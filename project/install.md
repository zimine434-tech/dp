# Установка и запуск

## Установка зависимостей

- `composer install` — установка зависимых PHP-пакетов.
- `npm install` — установка зависимостей клиентской части.
- `composer run setup` — быстрая первичная настройка (установка, ключ, миграции, сборка).

## Настройка окружения

1. Скопируйте файл конфигурации:
   ```
   copy .env.example .env
   ```
2. Откройте `.env` и заполните параметры подключения к БД, LDAP и другие настройки окружения.
3. Сгенерируйте ключ приложения:
   ```
   php artisan key:generate
   ```

## База данных

Выполните миграции:
```
php artisan migrate
```

## Сборка клиентской части

```
npm run build
```

## Запуск

Запустите веб-сервер PHP:
```
php artisan serve
```

Запустите сборщик клиентской части в режиме разработки:
```
npm run dev
```

Затем откройте в браузере: **aviator.irkat.ru**
